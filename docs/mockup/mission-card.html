关键设计抉择 · 一句话清单
  • 展开方向:reserve 后从右向左展开三栏(动画 scaleX 从 0.85 起步, transform-origin: right center),保证不挤动其他 Twitter UI 元素
  • 三点进度:实心 / 空心 + 横线连接,完成段亮色。比 stepper 盒子轻盈
  • 动作引导:中间用 <kbd> 视觉强调动作名词(赞 / 转 / 评论), 带 X 原版 SVG 让用户立刻认出
  • verify ready:冷却倒计时归零后,按钮从 outline → 实心 + ripple halo 动画,告诉用户"该点了"
  • error 不退回 idle:卡片保留三栏结构,只把 verify 换成 retry, 进度点标红显示卡在哪一步。语境保留
  • 不违反 impeccable:无 border-left stripe、无 gradient text、 无 glassmorphism;按钮渐变 OK(background-only)
