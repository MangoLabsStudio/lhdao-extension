# zkTLS：先读取、再确认、后证明

## 已确认目标

用户已确认：读取当前页面 → 展示数据 → 用户确认 → 生成证明 → 显示结果。
普通用户无需打开诊断日志，即可知道插件读取了哪个网站、账号和哪些数据。
本次只改变采集与证明的交互，不改变 Buyer 的业务规则，不绕过后端验证。

## 当前代码与问题

- `src/lib/zktls/runtime.ts` 的 `proveCapturedRequest` 在存在 `trigger_paths` 时新建标签页，捕获请求后立即启动证明。
- `CaptureSession` 读取请求及请求头，不提供响应正文预览。
- `DiscoverySessionManager` 已能读取浏览器网络响应；应复用其采集、限额与脱敏能力，避免再造一套任意请求工具。
- `ProductExperienceCard` 主要显示进度与诊断，没有独立的数据预览与确认状态。
- 本轮实测捕获到了与已登录钱包不同的请求账号，并在 MPC 的 `accept_preprocessing` 阶段超时。这是两个独立问题；本方案不会把 UI 改动描述为超时修复。

## 最小交互

1. 用户在目标网站的已登录标签页点击「读取当前页面」。
2. 插件先显示「监听已就绪」，用户按提示刷新或打开对应历史记录。默认不新建页面、不切换账号、不执行充值或交易。
3. 每个条件显示来源网站、页面路径、读取时间、请求账号、响应中的归属钱包、读取状态和预览数据。
4. 有响应时展示受限长度的记录列表和按已保存规则计算的结果；无响应、空列表、解析失败、超限分别展示，不能统一显示成 0。
5. 可展开查看脱敏后的请求、响应和错误详情。主界面不要求用户理解 JSON 字段路径。
6. 底部提供「重新读取」「确认数据并开始证明」。确认后才允许启动 MPC 和证明工作器。
7. 后端返回后，分别显示「验证通过」「条件不满足」「数据范围不足」或「证明失败」，不混用这些结果。

## 账号与规则

- 请求账号与归属钱包分别显示；子账户 ID 不直接作为 EVM 地址比较。
- 归属钱包按已签名的账号绑定规则提取、格式化，并与后端可信会话中的待验证钱包核对。
- 不从页面文字、请求自身或用户口头确认推断钱包已匹配。可信钱包缺失、响应钱包缺失、存在多个不同钱包或不一致时，禁用确认并说明原因。
- 用户确认表示同意使用这批数据，不代表钱包所有权或业务达标已经验证。
- 条件名称、币种、精度、聚合、时间范围与阈值使用已保存规则。不增加 Nado 专用地址黑名单，不默认 7 天，不把不同币种静默换算。
- 多个条件各自列出来源与状态。需要先验证账号绑定的条件，按现有依赖顺序执行；未就绪的条件不能冒充已预览或已证明。

## 数据与生命周期

- 网络监听仅限用户明确授权的当前标签页及已签名的来源约束。
- 采集结果是「本地预览，尚未验证」，不上传到 Buyer 样例接口，不写入长期存储。
- Cookie、Authorization、会话令牌、签名凭证及其他既有强制隐藏字段继续脱敏。不得为了展示原文解除隐藏。
- 使用已有正文大小、条数和会话时长限制。截断必须可见，不能基于截断数据宣称完整范围达标。
- 预览与确认绑定任务、配置版本、连接器、标签页、账号和规范化请求。确认消息只携带预览标识，不允许 UI 自行提供或替换证明数据。
- 重新读取、导航到其他网站、关闭标签页、退出账号、任务或配置切换、会话过期、插件重载均使旧确认失效。
- 证明精确重放已确认的请求。响应可能变化，最终结果以新生成的证明和后端验证为准，不承诺与预览数值完全一致。
- 不允许两次点击重复启动证明。确认前不长期占用待启动的证明工作器；需要创建或续建会话时重新检查有效期和版本。

## 复用边界

- 插件：扩展现有采集能力支持当前标签页预览；控制器保存临时预览状态；popup 展示来源、数据与确认操作；runtime 在确认之后才进入证明路径。
- 后端：优先复用现有可信会话与签名规则。如果当前接口未提供待验证钱包或计算规则，仅补齐必要的只读字段，不能用未经验证的页面信息填充。
- 前端工作台不改规则编辑体验；Verifier 的证明协议和业务校验标准不降低。
- 请求重复去重修复继续保留，其他未提交改动不覆盖。

## 验收

- 未确认时不会调用证明工作器，也不会注册用于 MPC 执行的 Verifier 会话。
- 相同请求去重；不同账号或参数不合并。用户确认后恰好启动一次对应证明。
- 正确账号可确认；错误、未知或歧义账号不可确认，并显示实际读到的账号。
- 覆盖请求有响应、无响应、空结果、非 JSON、超限、解析失败及多条件来源。
- 日志、UI 和传输中不出现被强制隐藏的凭证。
- 所有失效事件均阻止旧预览启动证明；不可跨标签页、任务、账号或配置版本复用。
- 原有 DOM 验证、队列依赖、重试、后端确认和去重回归继续通过。
- Beta 实测明确区分预览通过、证明启动、证明完成和后端达标。地区限制或 MPC 超时保持为未完成，不修改网络来绕过限制。

## 暂不包含

自动选择账号、任意脚本规则、新的 AI 配置功能、自动绕过网站限制、MPC 超时修复、部署、奖池发布或资金操作。
